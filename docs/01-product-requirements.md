# Product Requirements

## Must-have MVP
1. User authentication
2. Password vault
   - Save site/app name, username, password, notes
   - Encrypt stored passwords
   - Search vault entries
   - Add, edit, delete, favorite credentials
3. Password generator
4. Device manager
   - Add devices with name, type, OS, notes
   - Track update status
   - Mark trusted or risky
5. Login monitor
   - Recent login history
   - Track time, IP, device
   - Show failed attempts
6. Dashboard overview
   - Basic security status summary
   - Notifications for suspicious logins or outdated devices

## Should-have
1. Password strength checker
2. Copy password with auto-clear
3. 2FA status tracking for accounts
4. Recovery code tracking
5. Device encryption/antivirus status tracking
6. Security score per device
7. Unusual login location flagging
8. Activity feed of security events
9. Audit log for in-app changes
10. Data export/import

## Optional
1. Browser extension support
2. Backup/restore to cloud
3. Location-based login alerts
4. Session logout tracking
5. Dark mode customization
6. In-app multi-factor auth

## Non-functional Requirements
- Security-first defaults
- Minimal redundant logic
- Predictable API contracts
- Strong observability and auditability
- Documentation updated every sprint
